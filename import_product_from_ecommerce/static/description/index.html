Import Product from Ecommerce

Streamline your Odoo product management by importing products directly from e-commerce platforms. This module allows you to scrape product details, including images, descriptions, and prices, directly into your Odoo system.

Save Your Time! Creating New Products Has Never Been This Easy – Import Directly from E-commerce in Seconds!

Why Does This Module Matter?

In today’s fast-paced e-commerce environment, efficiency is key. This module empowers businesses to save time, reduce manual errors, and enhance product catalog accuracy by automating the product import process. Perfect for retailers, dropshippers, or any business managing products from multiple e-commerce sources.

Key Features

  • Import products from e-commerce platforms like Tokopedia.
  • Automatically fetch product details: name, description, price, and images.
  • Seamlessly integrate with Odoo's product management system.
  • User-friendly wizard interface for easy configuration.
  • Extensible architecture to support additional platforms (e.g., Shopee).

Installation

  1. Install the base module (Import Product from Ecommerce) via Odoo Apps.
  2. For Tokopedia-specific imports, install the extension module (Import Product from Ecommerce - Tokopedia).
  3. Ensure Python dependencies (requests, beautifulsoup4) are installed on your server.
  4. Start importing products using the wizard.

Screenshots & Installation Guide

1. Locate the e-commerce page containing the product you want to import.
2. Launch the Import Wizard.
3. Select the e-commerce site, enter the product URL, click the "Preview" button, and then click "Import."
4. Review the imported product details.
